# Threaded agents

`ThreadedAgent` demonstrates autonomous work performed by an agent thread.
`AutonomousAgent` shows a longer-running autonomous behavior. These samples
are useful for observing MaDKit lifecycle and scheduling logs.

[View the source code on GitHub](https://github.com/fmichel/MaDKit/tree/main/MDK-samples/src/main/java/madkit/sample/agent/threaded)
