# Launching samples

These examples show the smallest ways to start MaDKit agents and configure a
kernel. `HelloMaDKit` is the recommended first example. The builder examples
show typed and fluent configuration without assembling command-line strings.

Launchable classes: `HelloMaDKit`, `MultipleLaunching`, `CommandLineOptions`,
`MadkitBuilderDemo`, and `MadkitBuilderOptionsDemo`.
