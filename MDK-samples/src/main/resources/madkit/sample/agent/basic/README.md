# Agent samples

The agent examples progress from a minimal activation callback to agents with
parameters, autonomous behavior, lifecycle callbacks, management operations,
and daemon services.

Launchable classes include `SimpleAgent`, `AgentWithParameters`,
`ThreadedAgent`, `LifecycleLauncher`, and `DaemonDemo`. Long-running examples
can be stopped from their MaDKit window.

[View the source code on GitHub](https://github.com/fmichel/MaDKit/tree/main/MDK-samples/src/main/java/madkit/sample/agent/basic)
