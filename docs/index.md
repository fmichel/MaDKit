## Why MaDKit?

- **Open agent architecture** — define the internal model that fits your application.
- **Organization-centered communication** — agents use groups and roles to form societies.
- **Simulation-ready** — start with the core lifecycle and extend the engine as your model grows.
- **Java-native** — use the Java and Gradle ecosystem you already know.

## The core idea

MaDKit follows the **AGR model**: agents play roles in groups. This organizational layer gives a simulation or distributed application a clear structure without imposing a predefined agent architecture.
