Use the examples as a progressive learning path. Each project remains maintained in the repository that owns its build and source.

| Project | Best for |
|---|---|
| [`MDK-samples`](https://github.com/fmichel/MaDKit/tree/main/MDK-samples) | Focused examples for launching, lifecycle, organization, messaging, GUI, and chart-fx. |
| [`MDK-simu-template`](https://github.com/fmichel/MaDKit/tree/main/MDK-simu-template) | A small starting point for a new simulation. |
| [`MDK-bees-app`](https://github.com/fmichel/MaDKit/tree/main/MDK-bees-app) | A complete organization-based simulation with dynamically formed groups and roles. |
| [`MDK-marketorg-app`](https://github.com/fmichel/MaDKit/tree/main/MDK-marketorg-app) | A travel market application with clients, brokers, and ticket providers. |

For automated validation commands and GUI smoke-test boundaries, see the detailed [`MDK-samples/README.md`](https://github.com/fmichel/MaDKit/blob/main/MDK-samples/README.md).
