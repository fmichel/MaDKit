# ChartFX samples

These JavaFX simulations display live MaDKit data using ChartFX. The
population chart tracks role populations; the metric chart plots average agent
energy by role.

Launchable classes: `PopulationChartLauncher` and `MetricChartLauncher`.
The launcher supplies `--start` automatically. A graphical display is
required, and the simulations should be stopped when no longer needed.
